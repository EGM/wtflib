# wtflib

A small, intentionally organized toolbox of reusable building blocks extracted from other projects. Over time, certain helpers, types, and utilities proved general enough to stand on their own, so they were collected here instead of being re‑implemented across multiple codebases.

`wtflib` groups code by **kind** (widgets, types, functions, interfaces) and then by **domain** (strings, math, arrays, etc.). This keeps the library predictable, discoverable, and easy to extend as new primitives emerge.

The goal is not to provide a large framework or a comprehensive standard library replacement. Instead, `wtflib` serves as a curated set of small, focused tools that solve common problems cleanly and consistently.
